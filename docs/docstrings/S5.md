S5 over a full sequence (Smith et al., 2023).

Runs an `S5Cell` over the time axis with an associative parallel scan. A single diagonal state, shared across features, mixes all input channels (multi-input multi-output). Returns the output at every step and the final complex state.

Parameters
----------
in_dim : int
    Input and output feature dimension.
state_dim : int
    Shared state size, stored as `state_dim // 2` conjugate-pair eigenvalues.
dt_min : float, default=0.001
    Lower bound of the initial timestep range (sampled log-uniform).
dt_max : float, default=0.1
    Upper bound of the initial timestep range.
w_init : Initializer
    Initializer for the `B` and `C` projections. Glorot normal by default.
d_init : Initializer
    Initializer for the `D` skip term. Zeros by default.
key : PRNGKeyArray
    RNG key for parameter initialization. Keyword-only.

Attributes
----------
cell : S5Cell
    The wrapped single-step cell holding the parameters.

Notes
-----
The output dimension equals `in_dim`. Pass `hx` to override the default zero initial state. See [Conventions](../conventions.md#ssm).

Examples
--------
>>> s5 = nn.S5(3, 8, key=key)
>>> outputs, h = s5(x)          # (b, t, 3) -> (b, t, 3), (b, 4)
>>> outputs, h = s5(x, hx=h0)   # custom initial state
