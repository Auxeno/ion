# Blocks

Blocks compose existing modules without hiding their parameters. `Sequential` chains callables, `MLP` builds a stack of linear layers, `Residual` adds a module's output to its input, `Bidirectional` runs sequence modules in both time directions, and `Ensemble` constructs and evaluates independent copies of one model.
